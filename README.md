# Strong Legs & Core Plan

A 12-week strength program (3 full-body days + a 20-minute arm day) with gym/home versions, form cues, demo links, a rest timer and a workout log.

- Static web app: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`
- Works offline after the first visit; installable on iPhone via Safari > Share > Add to Home Screen
- Workout log is stored on the device (localStorage). Use the Backup section to save/restore a JSON file.
- Hosted with GitHub Pages from the `main` branch root.

To update: edit `index.html`, bump `CACHE` in `sw.js`, commit and push.
